HyperSample is a desktop application designed to support statistical inference and sampling decisions in seized drug analysis. After downloading and unzipping the installation package, users can run the application locally.
 
HyperSample provides tools for estimating the composition of positive items, such as items containing a target drug, and negative items, such as items not containing the target drug, in a population. It also supports sample-size calculation and evaluation of confidence levels under various sampling scenarios.
